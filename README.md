# better-xitter

A tiny Chrome-only extension to clean up your experience on x.com.

## Install in Chrome

- Download and extract: [better-xitter-chrome.zip](https://github.com/NotWadeGrimridge/better-xitter/releases/latest/download/better-xitter-chrome.zip)
- Open `chrome://extensions`.
- Enable “Developer mode”.
- Click “Load unpacked” and select the extracted folder (the one containing `manifest.json`).
